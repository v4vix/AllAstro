# Daily Brief — Reusable (every morning, 5 minutes)

> Daily brief. Yesterday: [1–2 lines on what happened, or "nothing"].
> Today I have [N] hours.
>
> Give me exactly 5 bullets:
> 1. Yesterday's result in one line (call out anything that changes the plan).
> 2. Today's #1 task (from this week's brief — don't invent new work).
> 3. Two supporting tasks, time-boxed.
> 4. The one metric to move today.
> 5. The one risk or follow-up I must not drop.
>
> If I have a batch task today (outreach, content, deliverable), draft it now
> in the same reply.
