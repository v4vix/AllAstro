# Process: AI SOP / Onboarding System Creator

**Idea #20** · **Monetization:** project fee + template products + retainer ·
**Time to first revenue:** 2–5 weeks · **Weekly hours:** 10–15

## Snapshot

Turn how a business actually works into documented SOPs, onboarding
checklists, and training material — extracted from interviews, call
recordings, and screen-share walkthroughs. Meta play: it uses this OS's own
methodology, and every client teaches me patterns I can productize (sell the
templates — idea #16 synergy).

**Pros:** every growing SMB needs it and dreads doing it, high project fees,
natural retainer (docs rot), direct path to a template product line.
**Cons:** sales cycle slower ("important not urgent"), extraction requires
real founder/staff time, businesses underestimate their own undocumented
complexity.
**Mitigations:** anchor to a trigger event (new hire incoming, owner
vacation, sale prep) in all marketing; fixed-scope packages by process count;
"one process free" as the wedge.

## Pipeline (per engagement)

1. **Extract:** structured interview (Claude generates the question script
   per process type) — recorded; or client records themselves doing the task.
2. **Draft:** transcript → Claude produces the SOP: purpose, roles, steps
   with screenshots-needed markers, decision points, edge cases, "done"
   criteria.
3. **Verify:** the person who does the task reviews; a NEW person attempts
   the task using only the SOP — gaps found become revisions.
4. **Package:** SOP library organized by role; 30-60-90 onboarding plan
   generated from the library; quick-reference cards.
5. **Retainer:** quarterly review — what changed, which SOPs rotted, update.
6. **Review seat:** I run the extraction interviews (relationship + judgment)
   and confirm the verify step actually happened before invoicing.
