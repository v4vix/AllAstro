# Decision Log

Append-only. Claude: reference past entries before proposing anything that
re-opens a settled question; if new evidence justifies re-opening one, say so
explicitly and cite the entry.

## Format

```
YYYY-MM-DD | [DECISION|EXPERIMENT|KILL|PIVOT|SCALE] | one-line summary | why | review date (optional)
```
