# 15 Unconventional / Under-the-Radar Niches

Less saturated than generic "AI for marketers" plays. Passionate, underserved
communities with high willingness to pay for specialized tools. Claude: score
these alongside the 20 core ideas during Week 0 selection; each maps to one of
the 20 process-file shapes (noted per niche).

Format per niche: **who pays · wedge product · price point · where to validate**.

1. **AI for Beekeeping / Urban Farming** — hobbyist + sideline beekeepers and
   urban farms. Wedge: hive/crop health report generator from inspection notes
   + local bloom/weather calendar. $9–19/mo (shape: #5 vertical tool).
   Validate: r/Beekeeping, local beekeeping associations.
2. **Senior Tech Companionship Agents** — adult children buying for parents.
   Wedge: simplified daily check-in companion with memory + family digest
   email. $19–39/mo, family plan (shape: #5/#15). Validate: caregiver forums,
   senior-center partnerships. Extra care: privacy, honesty about being AI.
3. **Indie Game Soundtrack Composer Assistant** — indie devs on tight budgets.
   Wedge: adaptive-music spec generator + licensing-ready track briefs +
   procedural stems workflow. $29–79 per project pack (shape: #16).
   Validate: itch.io forums, gamedev Discords.
4. **Rare Book / Antiquarian Inventory AI** — dealers and serious collectors.
   Wedge: photo/notes → catalog entries with condition grading language +
   comparable-sale research briefs. $49–99/mo (shape: #8 document tool).
   Validate: ABAA dealer lists, book-fair exhibitors. Valuations are
   estimates — human appraiser disclaimer.
5. **Micro-SaaS for Specific Hobbies** (e.g., aquarium parameter tracking) —
   obsessive hobbyists. Wedge: log parameters → trend alerts + plain-English
   "what's wrong with my tank" analysis. $5–12/mo (shape: #5).
   Validate: the hobby's biggest subreddit — read the weekly help threads.
6. **AI for Local Government Compliance** — small-town clerks and managers.
   Wedge: permit-application pre-check + public-notice drafting + records
   request summarization. $200–500/mo per town (shape: #9/#8). Validate:
   municipal leagues, city-clerk associations. Long sales cycle, near-zero churn.
7. **Pet DNA + Behavior Prediction Service** — new pet owners post-DNA-test.
   Wedge: DNA report + owner questionnaire → personalized training and
   health-watch plan. $29–49 one-time + $9/mo updates (shape: #14).
   Validate: dog-breed subreddits, DNA-test review threads. Not vet advice.
8. **Vintage Watch / Luxury Authentication Agent** — resellers and buyers.
   Wedge: listing-photo checklist analysis + red-flag report + provenance
   question script for sellers. $10–25 per check (shape: #4 usage-based).
   Validate: watch forums, r/Watches. Position as "pre-purchase research
   aid," never a guarantee.
9. **AI for Choir Directors** — church and community choir directors. Wedge:
   arrangement suggestions by voicing, rehearsal-schedule planner, practice
   guides per section. $15–29/mo (shape: #5). Validate: choral director
   Facebook groups, ACDA communities.
10. **Off-Grid / Van Life Resource Optimizer** — vanlifers and off-grid
    households. Wedge: power-budget planner (solar/battery vs appliances) +
    route/resupply briefs. $19–39 one-time app or pack (shape: #16).
    Validate: r/vandwellers, off-grid YouTube comment sections.
11. **AI for Board Game Designers** — aspiring and indie designers. Wedge:
    rulebook clarity review + balance simulation briefs + playtest question
    scripts. $19–49 per review (shape: #4/#16). Validate: BGG design forums,
    Tabletop Creators communities.
12. **Herbalism / Traditional Medicine Knowledge Base Agent** — practitioners
    and serious students. Wedge: cross-referenced knowledge base with source
    citations + interaction warnings + study guides. $19–39/mo (shape: #14).
    Validate: herbalism schools' student groups. Hard safety rails: educational
    only, cite sources, medical disclaimers everywhere.
13. **AI for Competitive Puzzle / Escape Room Creators** — room owners and
    puzzle-hunt designers. Wedge: puzzle-flow difficulty analysis, hint-system
    scripts, themed narrative generation. $49–99 per room design pack
    (shape: #16/#9). Validate: escape-room owner Facebook groups (very active).
14. **Small Orchestra / Ensemble Tour Planner** — ensemble managers (often a
    volunteer musician). Wedge: tour logistics briefs — venues, travel
    manifests, per-diem budgets, grant-application drafts. $99–299 per tour or
    $49/mo (shape: #9). Validate: regional arts councils, ensemble manager lists.
15. **AI for Mushroom Foraging & Mycology** — foragers, mycology clubs.
    Wedge: study guides, spore-print logging, regional season calendars,
    club-newsletter engine. $9–19/mo (shape: #14/#1). Validate: r/mycology,
    local mycological societies. NEVER edibility verdicts — identification
    is a human expert's call; the tool teaches and logs, with hard warnings.

## Selection heuristics for weird niches

- **Passion + money:** the hobby must have expensive gear or professional
  stakes — that's the willingness-to-pay proxy.
- **Findable community:** one subreddit/forum/association where 5,000+ of
  them already gather, or validation costs too much.
- **You + the niche:** personal connection to the niche is worth 2 points in
  scoring — these communities smell tourists instantly.
- **Safety-critical niches** (mushrooms, herbalism, seniors) carry extra
  responsibility: educational framing, expert referral paths, and
  disclaimers are part of the product, not fine print.
